# One-Hand-Operated-Nail-Clipper
Conventional nail clippers require two‑hand coordination for stable holding and squeezing, which creates barriers for individuals who only have functional use of a single hand. This project presents an assistive‑technology invention: a multi‑purpose nail clipper designed for single‑hand operation.
